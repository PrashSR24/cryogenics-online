Cryogenics Online: static site (no build step needed)

Upload everything in this folder to the root of a GitHub repository:
index.html, contact.html, 404.html, robots.txt, sitemap.xml, assets/ and lessons/.
Then turn on GitHub Pages (Settings, Pages, branch main, folder / root).

The addresses in the canonical tags, sitemap.xml and robots.txt use
https://cryogenics-online.com . If you launch first on a github.io address,
ask for the files to be regenerated with that address.

After the site is live, add it to Google Search Console and submit
https://YOUR-ADDRESS/sitemap.xml
