Duhamel’s Theorem & Green’s Functions

Building responses to arbitrary time-varying boundaries and sources from a single elementary solution.

Lecture 35

Duhamel’s method for time-dependent boundary conditions

Real boundaries rarely jump to a constant value and stay there. A furnace wall ramps up, a brake disc heats in pulses, a building facade follows the sun. Duhamel's insight: solve the problem once for a unit step, and you have solved it for every possible time history.

Let \(\Phi(\mathbf r,t)\) be the response to a boundary condition that jumps from 0 to 1 at \(t = 0\), with zero initial temperature and everything else homogeneous. A time-varying boundary value \(f(t)\) can be approximated by a staircase of small steps \(\Delta f_i\) at times \(\tau_i\). By linearity each step produces \(\Delta f_i\,\Phi(\mathbf r, t - \tau_i)\), and the responses add. As the steps shrink:

Duhamel’s superposition integral$$T(\mathbf r,t) = f(0)\,\Phi(\mathbf r,t) + \int_0^t\frac{df(\tau)}{d\tau}\,\Phi(\mathbf r,t-\tau)\,d\tau = \frac{\partial}{\partial t}\int_0^tf(\tau)\,\Phi(\mathbf r,t-\tau)\,d\tau$$

The two forms are equivalent; integrate by parts to go from one to the other. The second form avoids differentiating \(f\), which helps when \(f\) is measured data. The method also applies to time-varying sources: the response to \(\dot q(\mathbf r)g(t)\) is \(\partial_t\int_0^tg(\tau)\Phi_q(\mathbf r,t-\tau)d\tau\), where \(\Phi_q\) is the response to \(\dot q(\mathbf r)\) switched on at \(t = 0\).

Physical interpretation

The body has memory, and that memory fades. A boundary event at time \(\tau\) is felt at time \(t\) through \(\Phi(\mathbf r, t-\tau)\). Once \(t - \tau\) exceeds the diffusion time to the point of interest, the event is fully absorbed into the response. Recent history matters most; ancient history matters only through its cumulative effect. This is mathematically identical to the convolution of an input signal with a system's step response in control theory. A solid behaves as a linear, time-invariant filter.

Lecture 36

Discontinuities in the boundary history

If \(f(t)\) jumps by \(\Delta f_j\) at \(t = t_j\), the derivative contains a Dirac delta \(\Delta f_j\,\delta(t - t_j)\). The integral picks up a discrete term:

$$T(\mathbf r,t) = f(0)\Phi(\mathbf r,t) + \int_0^t f'(\tau)\Phi(\mathbf r,t-\tau)\,d\tau + \sum_{t_j\lt t}\Delta f_j\,\Phi(\mathbf r,t - t_j)$$

where the integral now covers only the smooth parts of \(f\). A boundary that is switched on at \(t_1\) and off at \(t_2\) gives \(T = \Phi(t - t_1) - \Phi(t - t_2)\). The response to a pulse is the difference of two delayed step responses. Choose "pulse" or "step at t₁" in the simulation above to see it.

Lecture 37

Applications of Duhamel’s method

Example 1: ramped wall. A plate of thickness \(L\) at zero temperature has \(T(0,t) = 0\) and \(T(L,t) = At\). The step response with \(T(L) = 1\) is

$$\Phi(x,t) = \frac{x}{L} + \frac{2}{\pi}\sum_{n=1}^\infty\frac{(-1)^n}{n}\sin\frac{n\pi x}{L}\,e^{-\alpha n^2\pi^2t/L^2}$$

With \(f = At\), \(f(0) = 0\) and \(f' = A\), Duhamel's integral gives

Ramped boundary$$T(x,t) = A\left[\frac{xt}{L} + \frac{2L^2}{\alpha\pi^3}\sum_{n=1}^\infty\frac{(-1)^n}{n^3}\sin\frac{n\pi x}{L}\left(1 - e^{-\alpha n^2\pi^2t/L^2}\right)\right]$$

At long times, \(T\to A\left[\frac{xt}{L} - \frac{L^2}{6\alpha}\frac{x}{L}\left(1 - \frac{x^2}{L^2}\right)\right]\). The interior lags the linear profile by a fixed, cubic-shaped deficit, a quasi-steady state in which the whole profile rises at rate \(A\,x/L\).

Example 3: cylinder with \(T(r_0,t) = f(t)\). With \(\Phi(r,t) = 1 - 2\sum_n\frac{J_0(\lambda_nr)}{\lambda_nr_0J_1(\lambda_nr_0)}e^{-\alpha\lambda_n^2t}\) and \(J_0(\lambda_nr_0) = 0\):

$$T(r,t) = f(t) - \frac{2}{r_0}\sum_n\frac{J_0(\lambda_nr)}{\lambda_nJ_1(\lambda_nr_0)}\left[f(0)e^{-\alpha\lambda_n^2t} + \int_0^tf'(\tau)e^{-\alpha\lambda_n^2(t-\tau)}d\tau\right]$$

Example 4: sphere. The same structure holds with \(\Phi = 1 + \frac{2r_0}{\pi r}\sum_n\frac{(-1)^n}{n}\sin\frac{n\pi r}{r_0}e^{-\alpha n^2\pi^2t/r_0^2}\). Example 5: cylinder with time-varying generation \(\dot q(t)\). Use \(\Phi_q\), the response to unit generation switched on at \(t = 0\), which tends to \(\frac{r_0^2 - r^2}{4k}\), and apply the same convolution to \(\dot q(t)\).

In the real world

Inverse heat conduction, the estimation of surface heat flux from interior thermocouples (rocket nozzles, quench probes, re-entry tiles), is Duhamel's integral run backwards. Because diffusion damps high frequencies, the inversion amplifies measurement noise, so practical methods add regularisation. Understanding the forward convolution is the first step.

Lecture 38

Introduction to Green’s functions

Duhamel generalises the boundary history. Green's functions generalise everything at once: initial data, sources anywhere in space and time, and every boundary. Define \(G(\mathbf r,t\,|\,\mathbf r',\tau)\) as the temperature at \((\mathbf r, t)\) caused by an instantaneous point source of unit energy (1 J per \(\rho c\), so that it produces a unit temperature-volume) released at \(\mathbf r'\) at time \(\tau\), in the body with homogeneous boundary conditions:

$$\frac{1}{\alpha}\frac{\partial G}{\partial t} = \nabla^2G + \frac{1}{\alpha}\delta(\mathbf r - \mathbf r')\,\delta(t - \tau),\qquad G = 0\ \text{for } t\lt\tau$$

Then the solution of the general problem with initial temperature \(F\), source \(\dot q\), and boundary data \(f_i\) on surfaces \(S_i\) is a sum of three integrals:

Green’s function solution$$T(\mathbf r,t) = \int_R G\big|_{\tau=0}F(\mathbf r')\,dv' + \frac{\alpha}{k}\int_0^t\!\!\int_R G\,\dot q(\mathbf r',\tau)\,dv'\,d\tau + \alpha\int_0^t\sum_i\oint_{S_i}\left[\frac{G}{k_i}f_i\right]_{\text{2nd, 3rd kind}}\text{ or }\left[-\frac{\partial G}{\partial n'_i}f_i\right]_{\text{1st kind}}dS_i'\,d\tau$$

Read it physically. The initial temperature is a collection of instantaneous sources at \(\tau = 0\). The generation is a continuous release of sources. A prescribed flux at a boundary is a surface source. A prescribed temperature acts as a dipole layer, which is why the normal derivative of \(G\) appears.

Reciprocity. \(G(\mathbf r,t\,|\,\mathbf r',\tau) = G(\mathbf r', -\tau\,|\,\mathbf r, -t)\): the effect at A of a pulse at B equals the effect at B of a pulse at A, with time reversed.

Lecture 39

Determining Green’s functions

The practical route: solve the homogeneous version of the problem with an arbitrary initial temperature \(F\), by separation of variables or transforms. Rearrange the answer as \(\int G|_{\tau=0}F\,dv'\), read off the kernel, and replace \(t\) by \(t - \tau\).

Infinite line. Module 6 gave \(T = \frac{1}{\sqrt{4\pi\alpha t}}\int F(x')e^{-(x-x')^2/4\alpha t}dx'\), so

$$G_\infty(x,t\,|\,x',\tau) = \frac{1}{\sqrt{4\pi\alpha(t-\tau)}}\exp\!\left[-\frac{(x-x')^2}{4\alpha(t-\tau)}\right]$$

Semi-infinite line, \(x\ge0\). Add an image source at \(-x'\). Its sign is negative for \(T = 0\) at \(x = 0\) (the images cancel there) and positive for an insulated face (their slopes cancel):

Method of images$$G(x,t\,|\,x',\tau) = \frac{1}{\sqrt{4\pi\alpha(t-\tau)}}\left\{\exp\!\left[-\frac{(x-x')^2}{4\alpha(t-\tau)}\right]\mp\exp\!\left[-\frac{(x+x')^2}{4\alpha(t-\tau)}\right]\right\}$$

With \(F = 0\), \(\dot q = 0\) and \(T(0,t) = f(t)\), the boundary term gives \(T = \int_0^t f(\tau)\frac{x}{\sqrt{4\pi\alpha}(t-\tau)^{3/2}}e^{-x^2/4\alpha(t-\tau)}d\tau\). For constant \(f\) this is \(f\,\operatorname{erfc}(x/2\sqrt{\alpha t})\), as it must be. In 2D and 3D, products of 1D Green's functions give \(G\) for corners, strips and boxes, and \(G_{3D} = (4\pi\alpha t)^{-3/2}e^{-r^2/4\alpha t}\) for unbounded space.

Physical interpretation

The space–time map shows each source's influence spreading inside a parabolic "diffusion cone" \(x - x'\sim\sqrt{4\alpha(t - \tau)}\). Unlike a wave there is no sharp front: \(G\) is non-zero everywhere immediately, but exponentially small outside the cone. Every boundary condition is replaced by mirror sources. A cold wall is a sink image; an insulated wall is a source image. In a finite slab, the images repeat forever, and summing them is equivalent to the eigenfunction series of Module 4. Image sums converge fast at early times; eigenfunction series converge fast at late times.

import numpy as np
import matplotlib.pyplot as plt

L, alpha = 1.0, 1.0
x = np.linspace(0, L, 201)
n = np.arange(1, 201)

def Phi(x, t):  # unit step on T(L,t), T(0,t)=0, zero initial T
    t = np.maximum(t, 1e-12)
    return x/L + 2/np.pi*np.sum(((-1.0)**n/n)[:, None]*np.sin(np.outer(n, x)*np.pi/L)*np.exp(-alpha*(n*np.pi/L)[:, None]**2*t), axis=0)

def duhamel(f, t, x, N=2000):
    """T = f(0) Phi(t) + ∫ f'(tau) Phi(t - tau) dtau, by midpoint rule"""
    tau = (np.arange(N) + 0.5)*t/N; dt = t/N
    df = (f(tau + dt/2) - f(tau - dt/2))
    return f(0)*Phi(x, t) + sum(d*Phi(x, t - ta) for d, ta in zip(df, tau))

A = 1.0
f = lambda t: A*t
t = 0.5
T_num = duhamel(f, t, x, N=400)
T_ex = A*(x*t/L + 2*L**2/(alpha*np.pi**3)*np.sum(((-1.0)**n/n**3)[:, None]*np.sin(np.outer(n, x)*np.pi/L)*(1-np.exp(-alpha*(n*np.pi/L)[:, None]**2*t)), axis=0))
print("max |Duhamel numeric - closed form| =", np.abs(T_num - T_ex).max())
plt.plot(x, T_ex, label='closed form'); plt.plot(x, T_num, '--', label='Duhamel (numerical)')
plt.xlabel('x / L'); plt.ylabel('T'); plt.legend(); plt.title('Ramped wall T(L,t) = A t')

# Green's function check: semi-infinite, T(0,t)=1 -> erfc
from scipy.special import erfc
xx, tt = 0.3, 0.2
tau = np.linspace(0, tt, 20001)[:-1]
kern = xx/np.sqrt(4*np.pi*alpha)/(tt - tau)**1.5*np.exp(-xx**2/(4*alpha*(tt - tau)))
print("Green integral:", np.trapz(kern, tau), "  erfc:", erfc(xx/(2*np.sqrt(alpha*tt))))
// Duhamel convolution for a sinusoidal wall temperature, slab 0..1, probe at x = 0.5
const Phi = (x, t) => { let s = x; for (let n = 1; n <= 80; n++) s += 2/Math.PI*((n%2?-1:1)/n)*Math.sin(n*Math.PI*x)*Math.exp(-n*n*Math.PI*Math.PI*Math.max(t,1e-9)); return s; };
const f = t => Math.sin(2*Math.PI*t);       // wall temperature history
const ts = M.linspace(0, 3, 300), x = 0.5, N = 300;
const T = ts.map(t => { let s = f(0)*Phi(x, t); const d = t/N; for (let i = 0; i < N; i++) { const tau = (i+0.5)*d; s += (f(tau+d/2)-f(tau-d/2))*Phi(x, t-tau); } return s; });
plot(ts, [ts.map(f), T], {xlabel:'αt/L²', ylabel:'T', labels:['wall f(t)', 'mid-plane response']});
print("amplitude ratio at mid-plane ≈", Math.max(...T.slice(200)).toFixed(3));
