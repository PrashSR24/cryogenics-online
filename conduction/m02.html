Sturm–Liouville Theory & Fourier Expansions

Why sines, Bessel functions and Legendre polynomials appear in every conduction solution, and how to expand anything in them.

Lecture 8

Characteristic-value problems and orthogonality

Every analytical solution in Modules 3 to 7 has the same shape: a sum of simple functions, each multiplied by a coefficient. This module explains where those functions come from, why they are orthogonal, and how to compute the coefficients. Get this right and separation of variables becomes routine bookkeeping.

Boundary-value vs characteristic-value problems

Take a homogeneous ODE containing a parameter \(\lambda\), with homogeneous boundary conditions at both ends:

$$\frac{d^2y}{dx^2} + \lambda^2 y = 0,\qquad y(0) = 0,\quad y(L) = 0$$

The general solution is \(y = C_1\sin\lambda x + C_2\cos\lambda x\). The left condition kills \(C_2\). The right condition demands \(C_1\sin\lambda L = 0\). Either \(C_1 = 0\), the trivial and useless solution, or \(\lambda\) takes one of the special values

$$\lambda_n = \frac{n\pi}{L},\qquad \phi_n(x) = \sin\frac{n\pi x}{L},\qquad n = 1,2,3,\dots$$

These are the characteristic values (eigenvalues) and characteristic functions (eigenfunctions). Change the sign, \(y'' - \lambda^2y = 0\) with the same conditions, and only the trivial solution survives, because \(\sinh\) and \(\cosh\) cannot vanish twice. A boundary-value problem may or may not be a characteristic-value problem; the reverse is always true.

The Sturm–Liouville form

Sturm–Liouville problem$$\frac{d}{dx}\!\left[p(x)\frac{dy}{dx}\right] + \left[q(x) + \lambda w(x)\right]y = 0,\qquad \alpha_1 y(a) + \beta_1 y'(a) = 0,\quad \alpha_2 y(b) + \beta_2 y'(b) = 0$$

with \(p, w > 0\) and \(q\le 0\) on \([a,b]\). Multiply the equation for \(\phi_m\) by \(\phi_n\), subtract the reverse, and integrate by parts. The boundary terms cancel because of the homogeneous conditions, leaving

$$(\lambda_n - \lambda_m)\int_a^b \phi_m\phi_n\,w(x)\,dx = 0\quad\Longrightarrow\quad \int_a^b \phi_m\phi_n\,w\,dx = \begin{cases}0 & m\ne n\\ N_n & m = n\end{cases}$$
  • All eigenvalues are real and non-negative, so writing \(\lambda\) as \(\lambda^2\) loses nothing.
  • Each eigenvalue has exactly one eigenfunction, except under periodic conditions, which give a sine–cosine pair.
  • The eigenfunctions form a complete orthogonal set: any piecewise-smooth \(f\) can be expanded in them.
  • Singular end points. If \(p(a) = 0\), as at \(r=0\) in a cylinder or sphere, the boundary condition there is replaced by "\(y\) and \(y'\) finite".
  • Periodic conditions. If \(p(a) = p(b)\), the conditions \(y(a)=y(b)\), \(y'(a)=y'(b)\) also give orthogonality. An example is a thin wire bent into a ring of circumference \(2L\).
Physical interpretation

Each eigenfunction is a thermal mode: a spatial pattern that keeps its shape as it decays. In a transient problem the \(n\)-th mode decays like \(e^{-\alpha\lambda_n^2t}\). Higher modes have more wiggles, larger \(\lambda_n\), and die off much faster. The boundary condition sets which patterns are allowed. An insulated end forces zero slope, a fixed-temperature end forces a node, and a convective end does something in between that depends on Bi. The eigenvalue picture above is the graphical solution you will reuse throughout Module 4.

Physical setting\(p\)\(q\)\(w\)Eigenfunctions
Slab, \(x\in(0,L)\)101\(\sin\lambda x,\ \cos\lambda x\)
Solid cylinder, \(r\in(0,r_0)\), order \(\nu\)\(r\)\(-\nu^2/r\)\(r\)\(J_\nu(\lambda r)\)

Lecture 9

Generalized Fourier series

Suppose \(f(x) = \sum_n A_n\phi_n(x)\) on \((a,b)\). Multiply both sides by \(\phi_m w\) and integrate. Orthogonality removes every term except \(n=m\):

Expansion coefficients$$A_n = \frac{1}{N_n}\int_a^b f(x)\,\phi_n(x)\,w(x)\,dx,\qquad N_n = \int_a^b \phi_n^2(x)\,w(x)\,dx$$

Each coefficient is a projection: how much of mode \(n\) the function contains. The coefficients do not change when you add more terms, which is the practical advantage of orthogonal bases over, say, a polynomial fit.

SeriesExpansion on \((0,L)\) or \((-L,L)\)Coefficients
Sine (odd extension)\(\sum_{n\ge1} B_n\sin\frac{n\pi x}{L}\)\(B_n = \frac{2}{L}\int_0^L f\sin\frac{n\pi x}{L}dx\)
Cosine (even extension)\(\frac{A_0}{2}+\sum_{n\ge1}A_n\cos\frac{n\pi x}{L}\)\(A_n = \frac{2}{L}\int_0^L f\cos\frac{n\pi x}{L}dx\)
Complete, period \(2L\)\(\frac{a_0}{2}+\sum (a_n\cos+b_n\sin)\frac{n\pi x}{L}\)\(a_n, b_n = \frac{1}{L}\int_{-L}^{L} f\,(\cos,\sin)\,dx\)

Convergence (Dirichlet conditions). Where \(f\) is continuous, the series converges to \(f\). At a jump it converges to the mean of the left and right limits. Near a jump, partial sums overshoot by about 9% of the jump. This Gibbs phenomenon does not shrink as you add terms; it only gets narrower.

Physical interpretation

Why do sine coefficients of \(f(x)=x\) fall off like \(1/n\), while those of \(x(L-x)\) fall like \(1/n^3\)? The odd extension of \(x\) has a jump at \(x=\pm L\); the odd extension of \(x(L-x)\) is smooth with only a kink in its second derivative. Smoothness buys convergence. In a transient problem this matters less than it seems, because the factor \(e^{-\alpha\lambda_n^2t}\) crushes high modes after a very short time. Diffusion is nature's low-pass filter.

Worked example: \(f(x) = x\) as a sine series on \((0,L)\)

$$B_n = \frac{2}{L}\int_0^L x\sin\frac{n\pi x}{L}dx = \frac{2L}{n\pi}(-1)^{n+1}\quad\Rightarrow\quad x = \frac{2L}{\pi}\sum_{n=1}^\infty\frac{(-1)^{n+1}}{n}\sin\frac{n\pi x}{L}$$

The series converges to \(x\) at \(x=0\) but to zero at \(x=L\), the mean across the jump of the odd periodic extension. Since \(x\) is odd, the same series also holds on \((-L,L)\).

Lecture 10

Bessel functions and Fourier–Bessel series

Separating variables in a cylinder produces Bessel's equation of order \(\nu\) for the radial part:

$$r^2R'' + rR' + (\lambda^2r^2 - \nu^2)R = 0\quad\Rightarrow\quad R = C_1J_\nu(\lambda r) + C_2Y_\nu(\lambda r)$$

\(Y_\nu\) is singular at \(r = 0\), so for a solid cylinder \(C_2 = 0\). In Sturm–Liouville form \(p = r\), \(q = -\nu^2/r\) and \(w = r\). The weight \(r\) is the cylindrical area element, so the outer region counts for more. The modified equation \(r^2R''+rR'-(\lambda^2r^2+\nu^2)R=0\) gives \(I_\nu\) and \(K_\nu\), which grow or decay monotonically like cosh and exp, and appear in the axial direction.

A homogeneous condition at \(r = r_0\) fixes the eigenvalues:

Condition at \(r_0\)Eigen-conditionNorm \(N_n = \int_0^{r_0}rJ_\nu^2(\lambda_nr)dr\)
\(R=0\)\(J_\nu(\lambda_nr_0) = 0\)\(\frac{r_0^2}{2}J_{\nu+1}^2(\lambda_nr_0)\)
\(R'=0\)\(J'_\nu(\lambda_nr_0) = 0\)\(\frac{r_0^2}{2}\left(1 - \frac{\nu^2}{\lambda_n^2r_0^2}\right)J_\nu^2(\lambda_nr_0)\)
\(kR' + hR=0\)\(\lambda_nr_0J'_\nu(\lambda_nr_0) + \mathrm{Bi}\,J_\nu(\lambda_nr_0) = 0\)\(\frac{r_0^2}{2}\left(1 + \frac{\mathrm{Bi}^2 - \nu^2}{\lambda_n^2r_0^2}\right)J_\nu^2(\lambda_nr_0)\)

The Fourier–Bessel series is then \(f(r) = \sum A_nJ_\nu(\lambda_nr)\) with \(A_n = \frac{1}{N_n}\int_0^{r_0}rf(r)J_\nu(\lambda_nr)\,dr\).

Worked example: \(f(r) = 1\) on \((0, r_0)\) with \(J_0(\lambda_nr_0) = 0\)

Use \(\int xJ_0(x)dx = xJ_1(x)\):

$$A_n = \frac{2}{\lambda_nr_0J_1(\lambda_nr_0)}\quad\Rightarrow\quad 1 = 1.6020\,J_0\!\left(2.4048\tfrac{r}{r_0}\right) - 1.0648\,J_0\!\left(5.5201\tfrac{r}{r_0}\right) + 0.8514\,J_0\!\left(8.6537\tfrac{r}{r_0}\right) - \dots$$

Every term vanishes at \(r = r_0\), so the series converges to 1 inside but to 0 at the wall. This is the cylindrical version of the Gibbs behaviour above.

Physical interpretation

\(J_0(\lambda_1r)\) is the fundamental cooling pattern of a long rod with its surface held cold. It peaks on the axis, bends smoothly, and reaches zero at the wall. It is the cylindrical cousin of \(\sin(\pi x/L)\). Its zeros are not evenly spaced near the axis but approach a spacing of \(\pi\) further out, because at large \(\lambda r\), \(J_0 \approx \sqrt{2/\pi\lambda r}\cos(\lambda r - \pi/4)\). The geometry stretches the inner wiggles.

Lecture 11

Legendre polynomials and Fourier–Legendre series

For a sphere with temperature depending on \(r\) and the polar angle \(\theta\), separation gives Legendre's equation in \(\mu = \cos\theta\):

$$\frac{d}{d\mu}\!\left[(1-\mu^2)\frac{dM}{d\mu}\right] + n(n+1)M = 0,\qquad -1\le\mu\le1$$

Here \(p(\pm1) = 0\), so both end points are singular, and finiteness at the poles selects integer \(n\) and the polynomial solutions \(P_n(\mu)\):

$$P_0 = 1,\quad P_1 = \mu,\quad P_2 = \tfrac12(3\mu^2-1),\quad P_3 = \tfrac12(5\mu^3-3\mu),\qquad (n+1)P_{n+1} = (2n+1)\mu P_n - nP_{n-1}$$
Fourier–Legendre series$$f(\mu) = \sum_{n=0}^\infty A_nP_n(\mu),\qquad A_n = \frac{2n+1}{2}\int_{-1}^{1}f(\mu)P_n(\mu)\,d\mu,\qquad \int_{-1}^1P_mP_n\,d\mu = \frac{2}{2n+1}\delta_{mn}$$

If only a hemisphere \(0\le\theta\le\pi/2\) is involved, with an insulated or isothermal equatorial plane, use only the even or only the odd polynomials respectively.

Worked example: heated cap

\(f(\theta) = \cos\theta\) on \(0\lt\theta\lt\pi/2\) and \(0\) on \(\pi/2\lt\theta\lt\pi\). That is, \(f(\mu)=\mu\) for \(\mu>0\) and \(0\) otherwise.

$$A_0 = \tfrac12\int_0^1\mu\,d\mu = \tfrac14,\qquad A_1 = \tfrac32\int_0^1\mu^2d\mu = \tfrac12,\qquad A_2 = \tfrac52\int_0^1\mu\cdot\tfrac12(3\mu^2-1)d\mu = \tfrac{5}{16}$$
Lecture 12

Tutorial: computing expansions in practice

The three expansions above are computed the same way: find the eigenvalues numerically when needed, evaluate the coefficient integrals (analytically or by quadrature), and sum. The code below does all three and checks them against the hand results. It is the toolkit you will reuse in every later module.

Exercise 1. Show that \(y''-\lambda^2y=0\), \(y(0)=y(L)=0\) has no non-trivial real solutions. \(y = C_1\sinh\lambda x + C_2\cosh\lambda x\); \(y(0) = 0\Rightarrow C_2 = 0\); \(\sinh\lambda L\ne0\) for \(\lambda\ne0\Rightarrow C_1 = 0\).

Exercise 2. Show that \(r^2R''+rR'-(\lambda^2r^2+\nu^2)R=0\) with \(R(0)\) finite and \(R(r_0)=0\) has only the trivial solution. Finiteness removes \(K_\nu\), and \(I_\nu\) has no positive zeros.

import numpy as np
from scipy.special import jn_zeros, j0, j1, eval_legendre
from scipy.integrate import quad
from scipy.optimize import brentq

# 1) Sine series of f(x) = x on (0, L): B_n = 2L(-1)^(n+1)/(n pi)
L = 1.0
B = [2/L*quad(lambda x: x*np.sin(n*np.pi*x/L), 0, L)[0] for n in range(1, 6)]
print("sine coeffs (quad):  ", np.round(B, 5))
print("sine coeffs (exact): ", np.round([2*L*(-1)**(n+1)/(n*np.pi) for n in range(1, 6)], 5))

# 2) Fourier-Bessel series of f(r) = 1 with J0(lambda r0) = 0
r0 = 1.0
z = jn_zeros(0, 4)
A = 2/(z*j1(z))
print("Fourier-Bessel A_n:  ", np.round(A, 4))      # 1.6020, -1.0648, 0.8514, ...

# 3) Fourier-Legendre for f(mu) = mu (mu>0), 0 (mu<0)
An = [(2*n+1)/2*quad(lambda m: m*eval_legendre(n, m), 0, 1)[0] for n in range(4)]
print("Legendre A_n:        ", np.round(An, 5))     # 0.25, 0.5, 0.3125, 0

# 4) Eigenvalues for a convective end: lambda L tan(lambda L) = Bi
Bi = 2.0
f = lambda b: b*np.tan(b) - Bi
roots = [brentq(f, n*np.pi + 1e-9, n*np.pi + np.pi/2 - 1e-9) for n in range(5)]
print("beta_n (Bi = 2):     ", np.round(roots, 5))
// Fourier-Bessel expansion of f(r) = 1, evaluated with the built-in Bessel routines
const z = M.besselZeros(0, 8);
const A = z.map(l => 2/(l*M.J1(l)));
print("zeros:", z);
print("A_n  :", A);
const r = M.linspace(0, 1, 200);
const sums = [1, 3, 8].map(N => r.map(x => A.slice(0, N).reduce((s, a, i) => s + a*M.J0(z[i]*x), 0)));
plot(r, sums, {xlabel:'r / r0', ylabel:'partial sum', labels:['N = 1','N = 3','N = 8']});
% Fourier-Bessel coefficients of f(r) = 1 (zeros found with fzero)
z = zeros(1,6); for n = 1:6, z(n) = fzero(@(x) besselj(0,x), [ (n-1)*pi+1, n*pi+1 ]); end
A = 2./(z.*besselj(1,z));
r = linspace(0,1,200); S = zeros(size(r));
for n = 1:6, S = S + A(n)*besselj(0, z(n)*r); end
plot(r, S); xlabel('r/r_0'); ylabel('partial sum'); disp(A)
