Lecture 13

Uniqueness and the method of separation of variables

Before solving, we need to know that a solution, once found, is the solution. Suppose two fields \(T_1, T_2\) satisfy the same heat equation, initial condition and boundary conditions. Their difference \(\Delta = T_1 - T_2\) satisfies the homogeneous problem with zero initial data. Now look at the "thermal energy norm" \(E(t) = \tfrac12\int_V\Delta^2\,dV\):

$$\frac{dE}{dt} = \alpha\int_V\Delta\nabla^2\Delta\,dV = \alpha\oint_A\Delta\frac{\partial\Delta}{\partial n}dA - \alpha\int_V|\nabla\Delta|^2dV = -\alpha\sum_i\frac{h_i}{k}\oint_{A_i}\Delta^2dA - \alpha\int_V|\nabla\Delta|^2dV\le 0$$

\(E\) starts at zero, can never grow, and is never negative, so it stays zero and \(T_1\equiv T_2\). A steady problem is unique too, up to an additive constant when every boundary is a prescribed flux.

Physical interpretation

Uniqueness is the second law in mathematical form. Diffusion only smooths. It cannot create a temperature difference that the boundaries and initial state do not demand. In practice this means you may guess a solution by any means (intuition, symmetry, superposition, a table) and, if it satisfies every condition, you are done.

The method

Separation of variables works when three things hold. The PDE and all but one of the boundary conditions are linear and homogeneous. The region fits the coordinate surfaces of an orthogonal system (a rectangle, cylinder or sphere). And the product form splits the PDE into ODEs. The recipe:

  1. Assume \(T = X(x)Y(y)\) (or \(R(r)Z(z)\), and so on) and substitute.
  2. Divide by \(XY\). Each side depends on a different variable, so both must equal a constant \(\pm\lambda^2\).
  3. Choose the sign so that the direction with two homogeneous conditions gets the oscillatory (Sturm–Liouville) equation. That direction supplies the eigenfunctions.
  4. Solve the other ODE with sinh/cosh, exponentials, or \(I_\nu/K_\nu\), \(r^{\pm n}\). Impose its homogeneous condition.
  5. Superpose all modes and fix the coefficients from the single non-homogeneous condition using orthogonality (Module 2).
The rule that decides everything

Eigenfunctions run along the direction that has homogeneous conditions at both ends. If more than one boundary is non-homogeneous, split the problem by superposition (Lecture 15) so that each sub-problem has exactly one.

Lecture 14

Rectangular coordinates

The classic: three cold edges, one hot

A long bar of cross-section \(L\times W\) has \(T=T_1\) on three sides and \(T=T_0\) on the side \(y=W\). Let \(\theta = (T - T_1)/(T_0 - T_1)\). The \(x\)-direction has homogeneous conditions at both ends, so it is the eigen-direction:

$$\theta = X(x)Y(y):\quad \frac{X''}{X} = -\frac{Y''}{Y} = -\lambda^2\ \Rightarrow\ X_n = \sin\lambda_nx,\ \lambda_n = \frac{n\pi}{L};\qquad Y_n = \sinh\lambda_ny$$

The sinh choice already satisfies \(\theta(x,0) = 0\). Matching \(\theta(x,W) = 1\) with a sine series gives

Steady 2D plate solution$$\frac{T - T_1}{T_0 - T_1} = \frac{2}{\pi}\sum_{n=1}^\infty\frac{1 - (-1)^n}{n}\,\sin\frac{n\pi x}{L}\,\frac{\sinh(n\pi y/L)}{\sinh(n\pi W/L)}$$

Worked example. \(T_1 = 0\) °C, \(T_0 = 100\) °C, \(L = 2W\). At the centre \((L/2, W/2)\):

$$T = \frac{200}{\pi}\sum_n\frac{1-(-1)^n}{n}\frac{\sin(n\pi/2)\sinh(n\pi/4)}{\sinh(n\pi/2)} = 48.061 - 3.987 + 0.502 - \dots = 44.512\ ^\circ\mathrm C$$

Three terms give 44.576 °C, already within 0.07 °C of the converged 44.512 °C. The series converges fast in the interior, because sinh ratios decay like \(e^{-n\pi(W-y)/L}\). It converges slowly near the hot edge, where the eigenfunctions must reproduce a discontinuity at the corners.

Physical interpretation

Each sine mode decays away from the hot edge over a distance \(L/n\pi\). Fine detail in the boundary temperature (high \(n\)) is forgotten within a short distance; only the smooth, low-\(n\) content reaches deep into the plate. This is Saint-Venant's principle for heat. It is why a thermocouple a few millimetres into a wall reads a smooth average of a patchy surface. Click the plate to probe the temperature and watch how few terms the interior needs.

A convective edge

If the edge \(x = b\) convects to a fluid at the reference temperature, the \(x\)-eigenfunctions become \(\cos\lambda_nx\) (insulated at 0) with \(\lambda_n\tan\lambda_nb = h/k\). The eigenvalues are no longer evenly spaced and come from the same graphical construction as in Module 2. The norm changes accordingly, but the procedure is identical.

Lecture 15

Superposition: non-homogeneous boundaries and sources

Because the heat equation is linear, the sum of two solutions is a solution. A plate with four non-zero edges \(f_1\) to \(f_4\) becomes four plates, each with one hot edge:

$$T(x,y) = T_1(x,y) + T_2(x,y) + T_3(x,y) + T_4(x,y)$$

Each \(T_i\) satisfies Laplace's equation, takes \(f_i\) on its own edge, and is zero on the other three. Adding them reproduces all four boundary conditions and the PDE.

Non-homogeneous PDE: internal generation

For \(\nabla^2T + \dot q/k = 0\) in a rectangle with \(T = 0\) on all sides, split \(T = \psi(x) + \phi(x,y)\). Let \(\psi\) carry the source in 1D: \(\psi'' + \dot q/k = 0\), \(\psi(0) = \psi(L) = 0\), so \(\psi = \frac{\dot q}{2k}x(L-x)\). Then \(\phi\) satisfies Laplace's equation with \(\phi = -\psi\) on \(y = 0, W\), a problem you can already solve. The trick works whenever the source can be absorbed by a one-dimensional particular solution.

In the real world

An electronics board with chips on top, a cooled base, and two clamped edges is exactly a superposition problem: one sub-problem per heat path, plus a particular solution for the volumetric heating of buried resistive traces. Before any FEA run, engineers use these closed-form series as sanity checks.

Lecture 16

Cylindrical coordinates: T(r, z)

A short solid cylinder (a stubby pin fin) of radius \(r_0\) and length \(L\) protrudes from a wall at \(T_0\). Its sides and tip are cooled so strongly (\(h\to\infty\)) that they sit at \(T_\infty\). Let \(\theta = T - T_\infty\):

$$\frac{1}{r}\frac{\partial}{\partial r}\!\left(r\frac{\partial\theta}{\partial r}\right) + \frac{\partial^2\theta}{\partial z^2} = 0,\quad \theta(r_0,z) = 0,\quad \theta(r,L) = 0,\quad \theta(r,0) = F(r)$$

The radial direction has two homogeneous conditions (finite at 0, zero at \(r_0\)), so it supplies the Bessel eigenfunctions \(J_0(\lambda_nr)\) with \(J_0(\lambda_nr_0) = 0\). The axial solution vanishing at \(z = L\) is \(\sinh\lambda_n(L - z)\):

Cylinder, uniform base temperature$$\frac{\theta(r,z)}{\theta_0} = \frac{2}{r_0}\sum_{n=1}^\infty\frac{J_0(\lambda_nr)}{\lambda_nJ_1(\lambda_nr_0)}\,\frac{\sinh\lambda_n(L-z)}{\sinh\lambda_nL}$$

Worked example. \(L/r_0 = 2\), point \(r/r_0 = 0.5\), \(z/L = 0.75\). With \(\alpha_n = \lambda_nr_0\) the zeros of \(J_0\):

$$\frac{\theta}{\theta_0} = 2\sum_n\frac{J_0(0.5\alpha_n)\,\sinh(0.5\alpha_n)}{\alpha_nJ_1(\alpha_n)\,\sinh(2\alpha_n)}\approx 0.0265$$
Physical interpretation

Compare with the 1D fin of Module 1. There, temperature was assumed uniform over each cross-section. Here, with \(h\to\infty\), the surface is pinned at \(T_\infty\) and the core stays hotter, so the profile is strongly two-dimensional. The 1D fin model is valid only when \(\mathrm{Bi} = hr_0/k\ll 1\). Raise \(L/r_0\) in the simulation: beyond about \(L/r_0 = 1.5\), the tip is essentially at \(T_\infty\), because the first mode decays like \(e^{-2.405z/r_0}\).

Lecture 17

Cylindrical coordinates: T(r, φ)

A long cylinder has its surface held at a temperature that varies around the circumference, \(T(r_0,\phi) = f(\phi)\). The azimuthal direction has periodic conditions, which give \(\sin n\phi\) and \(\cos n\phi\). The radial equation \(r^2R'' + rR' - n^2R = 0\) is equidimensional, with solutions \(r^{n}\) and \(r^{-n}\) (and \(\ln r\) for \(n = 0\)). Finiteness at the axis keeps only \(r^n\):

Interior of a circle$$T(r,\phi) = \frac{a_0}{2} + \sum_{n=1}^\infty\left(\frac{r}{r_0}\right)^n\left(a_n\cos n\phi + b_n\sin n\phi\right),\quad a_n, b_n = \frac{1}{\pi}\int_0^{2\pi}f(\phi')\left(\cos, \sin\right)n\phi'\,d\phi'$$

For the region outside a hole in a large plate, finiteness at infinity keeps \(r^{-n}\) instead: replace \((r/r_0)^n\) by \((r_0/r)^n\). Summing the series in closed form gives the Poisson integral \(T(r,\phi) = \frac{1}{2\pi}\int_0^{2\pi}\frac{(r_0^2 - r^2)f(\phi')}{r_0^2 - 2rr_0\cos(\phi - \phi') + r^2}d\phi'\).

Physical interpretation

The centre temperature is \(a_0/2\), the plain average of the surface temperature. This is the mean-value property of harmonic functions. The \(n\)-th harmonic shrinks as \((r/r_0)^n\) toward the centre, so a pipe wall heated on one side by sunlight, with \(n = 1\) dominant, has a nearly linear temperature across its bore. A pattern with many lobes is smoothed out within a thin skin.

Non-homogeneous PDE in a cylinder

With generation \(\dot q\) in a cylinder whose surface is at \(T_\infty\) and whose base is at \(T_0\), absorb the source in the 1D radial particular solution \(\psi(r) = \frac{\dot q}{4k}(r_0^2 - r^2)\). The remainder satisfies Laplace's equation with modified base data. This is the same split as in the rectangle.

Lecture 18

Spherical coordinates and extension to 3D

A solid sphere has surface temperature \(f(\theta)\) that depends only on polar angle. With \(\mu = \cos\theta\), \(T = R(r)M(\mu)\) separates into Legendre's equation for \(M\) (finite at both poles, so \(M = P_n(\mu)\)) and \(r^2R'' + 2rR' - n(n+1)R = 0\), with solutions \(r^n\) and \(r^{-(n+1)}\):

Solid sphere$$T(r,\theta) = \sum_{n=0}^\infty A_n\left(\frac{r}{r_0}\right)^nP_n(\cos\theta),\qquad A_n = \frac{2n+1}{2}\int_{-1}^{1}f(\mu)P_n(\mu)\,d\mu$$

For the exterior of a sphere, use \((r_0/r)^{n+1}\) instead. The centre is again the surface average, \(A_0\).

Three dimensions

For \(T(x,y,z)\) in a box with one non-homogeneous face, there are two eigen-directions. Assume \(T = X(x)Y(y)Z(z)\). With \(X_m = \sin\beta_mx\) and \(Y_n = \sin\gamma_ny\), the third direction gets \(\sinh\left(\sqrt{\beta_m^2 + \gamma_n^2}\,z\right)\), and the coefficients form a double series \(A_{mn}\), computed by a double orthogonality integral. In a cylinder \(T(r,\phi,z)\) the eigenfunctions are \(J_\nu(\lambda_{\nu n}r)\cos\nu\phi\), and so on.

A geometry that does not separate, but symmetry rescues it

A long prism with right isosceles triangular cross-section has \(T = 0\) on one leg, convection on the other leg, and an insulated hypotenuse. A triangle does not fit any coordinate system. But an insulated hypotenuse is a symmetry line: the triangle's solution is half of the solution in the square obtained by mirroring across the diagonal. The square has symmetric conditions and separates. Look for symmetry planes before reaching for numerics.

import numpy as np
from scipy.special import j0, j1, jn_zeros

# 1) Rectangular bar, L = 2W, centreline temperature (T0 = 100, T1 = 0)
def plate(x, y, L=2.0, W=1.0, N=200):
    n = np.arange(1, N+1)
    terms = (1-(-1.0)**n)/n*np.sin(n*np.pi*x/L)*np.exp(n*np.pi*(y-W)/L)*(1-np.exp(-2*n*np.pi*y/L))/(1-np.exp(-2*n*np.pi*W/L))
    return 200/np.pi*terms.sum()        # sinh ratio written with exponentials: no overflow
print(f"T(L/2, W/2) = {plate(1.0, 0.5):.3f} °C   (converged; 3 terms give 44.576)")
for N in (1, 2, 3, 5, 50):
    print(f"   N = {N:3d}: {plate(1.0, 0.5, N=N):.4f}")

# 2) Short cylinder with h -> infinity, L/r0 = 2, point r/r0 = 0.5, z/L = 0.75
a = jn_zeros(0, 60); Lr = 2.0; rr, zz = 0.5, 0.75
th = 2*np.sum(j0(a*rr)/(a*j1(a))*np.exp(-a*Lr*zz)*(1-np.exp(-2*a*Lr*(1-zz)))/(1-np.exp(-2*a*Lr)))
print(f"theta/theta0 at (0.5, 0.75) = {th:.5f}")

# 3) Sphere: surface hot on the upper hemisphere -> centre equals the surface mean
from scipy.special import eval_legendre
from scipy.integrate import quad
A = [(2*n+1)/2*quad(lambda m: eval_legendre(n, m), 0, 1)[0] for n in range(8)]
print("sphere A_n:", np.round(A, 4), " centre T =", A[0])
// Rectangular plate series: convergence at the centre and along the mid-line
const L = 2, W = 1;
function T(x, y, N) {
  let s = 0;
  for (let n = 1; n <= N; n += 2)   // only odd n survive
    s += (2/n)*Math.sin(n*Math.PI*x/L)*Math.exp(n*Math.PI*(y-W)/L)*(1-Math.exp(-2*n*Math.PI*y/L))/(1-Math.exp(-2*n*Math.PI*W/L));
  return 200/Math.PI*s;
}
[1, 3, 5, 51].forEach(N => print("N =", N, " T(L/2, W/2) =", T(1, 0.5, N)));
const ys = M.linspace(0, 1, 120);
plot(ys, [ys.map(y => T(1, y, 1)), ys.map(y => T(1, y, 5)), ys.map(y => T(1, y, 101))], {xlabel:'y / W', ylabel:'T on x = L/2 (°C)', labels:['N = 1','N = 5','N = 101']});
