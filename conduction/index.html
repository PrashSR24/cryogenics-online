How to use this course

Read, then break things

Each module follows its lectures in order. Read the derivation, then open the simulation beside it and try to break the result. Push a Biot number to infinity, set the Stefan number to zero, run an explicit scheme at Fo = 0.6. When a limit behaves the way the physical-interpretation box says it should, you understand the result. When it doesn't, you have found the edge of a model's validity, which is even more useful.

Code blocks have three tabs. JavaScript runs instantly in the page. Python (NumPy/SciPy/Matplotlib) runs in-browser on the hosted site, or can be copied into Jupyter. MATLAB versions are given where the original workflow uses pdepe, bvp4c or the PDE Toolbox.

Prerequisites

Undergraduate heat transfer, ordinary differential equations, and some vector calculus. Fourier series are developed from scratch in Module 2.

Why a cryogenics site teaches conduction

Almost every cryogenic design problem is a conduction problem at heart. Heat leaks through supports, current leads and multilayer insulation. Cool-down transients of cold masses take days. Ice and solid-hydrogen fronts move. Contact resistance at bolted joints, and conductivities that change tenfold between 300 K and 4 K, decide what works. Look for the green Cryogenic angle boxes throughout.
