Integral Transform Methods

Lecture 29

Introduction to integral transforms

Separation of variables needs homogeneous boundary conditions and a homogeneous PDE. Superposition can patch some cases, but time-dependent boundary temperatures and time-varying sources make it awkward. The integral transform technique handles them all in one systematic sweep.

An integral transform maps a function to a new variable through a kernel: \(\bar T(\lambda) = \int_a^bK(\lambda,x)\,T(x)\,dx\). The Laplace transform (Module 5) uses \(K = e^{-st}\) to remove time. Here we remove space, using the normalised eigenfunctions of the problem's own Sturm–Liouville operator as the kernel:

Finite integral transform pair$$\bar T_n(t) = \int_R K_n(\mathbf r)\,T(\mathbf r,t)\,dv\quad(\text{transform}),\qquad T(\mathbf r,t) = \sum_{n=1}^\infty K_n(\mathbf r)\,\bar T_n(t)\quad(\text{inversion}),\qquad K_n = \frac{\psi_n}{\sqrt{N_n}}$$

Apply the transform to \(\frac{1}{\alpha}\partial_tT = \nabla^2T + \dot q/k\). Green's second identity moves the Laplacian onto the kernel, which is an eigenfunction (\(\nabla^2K_n = -\lambda_n^2K_n\)). The boundary integrals that appear contain exactly the prescribed boundary data, whatever it is:

$$\frac{d\bar T_n}{dt} + \alpha\lambda_n^2\bar T_n = \alpha\left[\frac{\bar q_n(t)}{k} + \underbrace{\oint_S\left(K_n\frac{\partial T}{\partial n} - T\frac{\partial K_n}{\partial n}\right)dS}_{\text{known from the BCs}}\right]\equiv A_n(t),\qquad \bar T_n(0) = \bar F_n$$

Each mode is a first-order linear ODE with solution \(\bar T_n(t) = e^{-\alpha\lambda_n^2t}\left[\bar F_n + \int_0^te^{\alpha\lambda_n^2t'}A_n(t')dt'\right]\). Invert by summing. That is the whole method.

Recipe
  1. Write the homogeneous version of the problem and find its eigenfunctions. This gives the kernel \(K_n\) (from tables for slabs, cylinders and spheres with any combination of Dirichlet, Neumann and Robin ends).
  2. Transform the PDE, initial condition and boundary conditions to get one ODE per mode.
  3. Solve each ODE.
  4. Invert with the series.

Lectures 30–31

Transient conduction in a finite domain

Example. A slab \(0\le x\le L\) starts at \(F(x)\). Its face \(x = 0\) is insulated and \(x = L\) is held at \(f(t)\). A uniform source \(\dot q(t)\) may also act. The kernel is \(K_n = \sqrt{2/L}\cos\lambda_nx\) with \(\lambda_n = (2n-1)\pi/2L\). Transforming term by term:

$$\int_0^LK_n\frac{\partial^2T}{\partial x^2}dx = -\lambda_n^2\bar T_n - K_n'(L)\,f(t),\qquad K_n'(L) = -\sqrt{\tfrac{2}{L}}\,\lambda_n(-1)^{n+1}$$
Mode equation$$\frac{d\bar T_n}{dt} + \alpha\lambda_n^2\bar T_n = \alpha\sqrt{\frac{2}{L}}(-1)^{n+1}\left[\lambda_nf(t) + \frac{\dot q(t)}{k\lambda_n}\right],\qquad \bar T_n(0) = \sqrt{\frac{2}{L}}\int_0^LF(x)\cos\lambda_nx\,dx$$

The simulation below integrates these ODEs exactly in time and shows all three spaces at once: the physical temperature, the transform-space amplitudes \(\bar T_n(t)\), and the reconstructed field.

Physical interpretation

In transform space, a PDE becomes a bank of independent RC circuits. Mode \(n\) has time constant \(1/\alpha\lambda_n^2\) and is driven by its own share of the forcing. A slowly oscillating surface temperature drives the low modes, which can follow it. The high modes respond weakly and with a phase lag. This is the modal version of the damped thermal wave in Module 5.

Notice the small ripple at \(x = L\) when \(f(t)\ne0\). Every kernel vanishes at \(x = L\), so the series must reproduce a non-zero wall value from functions that are zero there. Convergence is slow at that point, though correct everywhere inside. The standard fix is to subtract a simple function that carries the boundary value (a "filter" or quasi-steady solution) and transform only the remainder.

Lecture 32

Steady conduction by repeated transforms

For steady multi-dimensional problems, apply a transform in each direction that has homogeneous conditions. Each application removes one second derivative. Transform in every direction and the PDE becomes an algebraic equation.

Example. A rectangle \(0\lt x\lt L\), \(0\lt y\lt W\) with all four edges at \(T = 0\) and a source \(\dot q(x,y)\). With sine kernels in both directions, \(K_m(x)K_n(y)\):

$$-(\beta_m^2 + \gamma_n^2)\,\bar T_{mn} + \frac{\bar q_{mn}}{k} = 0\quad\Rightarrow\quad T(x,y) = \frac{4}{LW}\sum_{m,n}\frac{\bar q_{mn}\sin\beta_mx\sin\gamma_ny}{k(\beta_m^2 + \gamma_n^2)},\quad \beta_m = \frac{m\pi}{L},\ \gamma_n = \frac{n\pi}{W}$$

Applied to the Module 3 plate with a hot edge \(T(x,W) = f(x)\), one transform in \(x\) leaves an ODE in \(y\), \(\bar T_m'' - \beta_m^2\bar T_m = 0\), with \(\bar T_m(W) = \bar f_m\). Its solution \(\bar f_m\sinh\beta_my/\sinh\beta_mW\) reproduces the separation-of-variables result exactly. The transform is the more general machine.

Physical interpretation

The factor \(1/(\beta_m^2 + \gamma_n^2)\) is a spatial low-pass filter. A source pattern's fine detail (large \(m, n\)) contributes little to the temperature, which is why the temperature field is always smoother than the heat source that drives it. Drag the source in the simulation. The temperature peak is rounded even for a point-like source, and it shrinks as the source approaches a cold wall.

Lecture 33

Transforms on semi-infinite and infinite domains

On an unbounded interval the eigenvalue spectrum is continuous and the sum becomes an integral. The kernels are the (co)sine and exponential Fourier transforms:

$$\bar T(\lambda,t) = \int_{-\infty}^{\infty}e^{i\lambda x}T\,dx,\qquad T = \frac{1}{2\pi}\int_{-\infty}^\infty e^{-i\lambda x}\bar T\,d\lambda;\qquad \frac{d\bar T}{dt} + \alpha\lambda^2\bar T = 0$$

For an infinite medium with initial temperature \(F(x)\), the result is the convolution of \(F\) with the Gaussian heat kernel:

Infinite medium$$T(x,t) = \frac{1}{\sqrt{4\pi\alpha t}}\int_{-\infty}^{\infty}F(x')\exp\!\left[-\frac{(x - x')^2}{4\alpha t}\right]dx'$$

For a semi-infinite medium, the sine transform (for \(T = 0\) at \(x=0\)) or cosine transform (insulated) gives the same kernel plus a mirror image. Module 7 calls this the method of images.

Lecture 34

Hankel transforms: cylindrical coordinates

For an unbounded radial coordinate the kernel is \(J_\nu(\lambda r)\), with weight \(r\):

Hankel transform of order ν$$\bar T(\lambda) = \int_0^\infty rJ_\nu(\lambda r)\,T(r)\,dr,\qquad T(r) = \int_0^\infty\lambda J_\nu(\lambda r)\,\bar T(\lambda)\,d\lambda,\qquad \mathcal H\!\left\{\frac{1}{r}\frac{d}{dr}\!\left(r\frac{dT}{dr}\right) - \frac{\nu^2}{r^2}T\right\} = -\lambda^2\bar T$$

Example. An infinite medium whose cylindrical core \(r\lt b\) starts at \(T_0\) while the rest is at 0. With \(\int_0^b rJ_0(\lambda r)dr = bJ_1(\lambda b)/\lambda\),

$$\frac{T(r,t)}{T_0} = b\int_0^\infty e^{-\alpha\lambda^2t}J_1(\lambda b)\,J_0(\lambda r)\,d\lambda,\qquad \frac{T(0,t)}{T_0} = 1 - e^{-b^2/4\alpha t}$$

Combined with a finite or semi-infinite transform in \(z\) and a Fourier series in \(\phi\), the same approach solves \(T(r,\phi,z)\) problems, such as a heated disk on the surface of a thick body.

Physical interpretation: dimension sets the decay rate

At long times the core's heat \(Q\) spreads over a region of size \(\sqrt{\alpha t}\) in \(d\) dimensions, so the centre temperature falls like \(Q/(\alpha t)^{d/2}\). That is \(t^{-1/2}\) for a planar slab, \(t^{-1}\) for a cylinder and \(t^{-3/2}\) for a sphere. The log–log plot in the simulation shows the three slopes. A hot fuel pellet (3D) cools much faster than a hot rod (2D) of the same radius, and a hot sheet (1D) slowest of all.

import numpy as np
import matplotlib.pyplot as plt

# Slab 0<x<L: insulated at 0, T(L,t) = f(t), uniform source q(t), T(x,0) = F(x)
L, alpha, k = 1.0, 1.0, 1.0
N = 60
n = np.arange(1, N+1); lam = (2*n-1)*np.pi/(2*L); s = (-1.0)**(n+1)
x = np.linspace(0, L, 301)
K = np.sqrt(2/L)*np.cos(np.outer(lam, x))           # kernels, shape (N, nx)

F = lambda x: 1 - x**2                              # initial profile (satisfies BCs)
Fbar = np.trapz(K*F(x), x, axis=1)                  # transformed initial condition
f = lambda t: 0.5*np.sin(2*np.pi*t)                 # oscillating wall temperature
q = lambda t: 2.0                                   # uniform generation

def A(t):   # forcing in each mode equation
    return alpha*np.sqrt(2/L)*s*(lam*f(t) + q(t)/(k*lam))

# exact exponential integrator over small steps (piecewise-constant forcing)
dt, Tb, t = 1e-3, Fbar.copy(), 0.0
snap = {}
for step in range(1, 2001):
    E = np.exp(-alpha*lam**2*dt)
    Tb = Tb*E + A(t + dt/2)*(1 - E)/(alpha*lam**2)
    t += dt
    if step in (50, 250, 1000, 2000): snap[round(t, 3)] = K.T @ Tb

for tt, T in snap.items(): plt.plot(x, T, label=f't = {tt}')
plt.xlabel('x / L'); plt.ylabel('T'); plt.legend(); plt.title('Finite Fourier (cosine) transform solution')
print("T(0) at t=2:", snap[2.0][0])
// Double finite sine transform: steady temperature from a square source in a cold square
const N = 40, Lx = 1, Ly = 1, x0 = 0.3, y0 = 0.6, w = 0.1;
// q̄_mn = ∫∫ q sin(mπx) sin(nπy) over the source square (q = 1 inside)
const qm = m => (Math.cos(m*Math.PI*(x0-w/2)) - Math.cos(m*Math.PI*(x0+w/2)))/(m*Math.PI);
const qn = n => (Math.cos(n*Math.PI*(y0-w/2)) - Math.cos(n*Math.PI*(y0+w/2)))/(n*Math.PI);
function T(x, y) {
  let s = 0;
  for (let m = 1; m <= N; m++) for (let n = 1; n <= N; n++)
    s += 4*qm(m)*qn(n)*Math.sin(m*Math.PI*x)*Math.sin(n*Math.PI*y)/((m*m + n*n)*Math.PI*Math.PI);
  return s;
}
const xs = M.linspace(0, 1, 120);
plot(xs, [xs.map(x => T(x, y0)), xs.map(x => T(x, 0.3))], {xlabel:'x', ylabel:'T k/q', labels:['through source (y = 0.6)', 'y = 0.3']});
print("peak T k/q ≈", T(x0, y0));
