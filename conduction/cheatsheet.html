Laws & the heat equation

$$\mathbf q'' = -k\nabla T,\qquad q''_i = -k_{ij}\partial_jT$$
$$\rho c\,\partial_tT = \nabla\cdot(k\nabla T) + \dot q,\qquad \alpha = k/\rho c$$
$$-k\,\partial_nT = h(T - T_\infty) + \varepsilon\sigma(T^4 - T_{sur}^4)$$

Dimensionless groups

$$\mathrm{Bi} = \frac{hL}{k},\quad \mathrm{Fo} = \frac{\alpha t}{L^2},\quad \mathrm{Ste} = \frac{c\Delta T}{L_f},\quad \mathrm{Pe} = \frac{uL}{2\alpha}$$
$$\text{lumped if } \mathrm{Bi} = hV/(kA_s)\lt 0.1:\ \ \theta/\theta_i = e^{-\mathrm{Bi\,Fo}}$$

$$m^2 = \frac{hP}{kA_c},\quad q_f = \sqrt{hPkA_c}\,\theta_b\tanh mL\ \ (\text{adiabatic tip})$$

Sturm–Liouville & expansions

$$A_n = \frac{1}{N_n}\int_a^bf\phi_nw\,dx;\quad J_0:\ w = r;\quad P_n:\ N_n = \tfrac{2}{2n+1}$$

Steady 2D plate

$$\frac{T - T_1}{T_0 - T_1} = \frac{2}{\pi}\sum_n\frac{1 - (-1)^n}{n}\sin\frac{n\pi x}{L}\frac{\sinh(n\pi y/L)}{\sinh(n\pi W/L)}$$
$$T(r,\phi) = \tfrac{a_0}{2} + \sum(r/r_0)^n(a_n\cos n\phi + b_n\sin n\phi)$$

Transient: plate, cylinder, sphere

$$\frac{\theta}{\theta_i} = \sum C_nX_n(\gamma_n\xi)e^{-\gamma_n^2\mathrm{Fo}},\quad \gamma\tan\gamma = \mathrm{Bi};\ \ \gamma\tfrac{J_1}{J_0} = \mathrm{Bi};\ \ 1 - \gamma\cot\gamma = \mathrm{Bi}$$
$$\theta_{\text{brick}} = \theta_{\text{plate},x}\,\theta_{\text{plate},y}\,\theta_{\text{plate},z}$$

Semi-infinite solids

$$T_c = \frac{e_1T_1 + e_2T_2}{e_1 + e_2},\ e = \sqrt{k\rho c};\quad d = \sqrt{2\alpha/\omega}$$

Integral transforms

$$\bar T_n = \int K_nT\,dv,\quad T = \sum K_n\bar T_n,\quad \dot{\bar T}_n + \alpha\lambda_n^2\bar T_n = A_n(t)$$
$$\mathcal H_\nu:\ \bar T = \int_0^\infty rJ_\nu(\lambda r)T\,dr,\ \ T = \int_0^\infty\lambda J_\nu\bar T\,d\lambda$$

Phase change

$$k_s\partial_xT_s - k_\ell\partial_xT_\ell = \rho L\dot s,\quad s = 2\lambda\sqrt{\alpha t}$$
$$\lambda e^{\lambda^2}\operatorname{erf}\lambda = \mathrm{Ste}/\sqrt\pi;\quad \text{quasi-steady } s = \sqrt{2\,\mathrm{Ste}\,\alpha t}$$
